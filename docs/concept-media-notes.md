## Clip construction

The new MP4s are ten-second, 1280×720 H.264 animated stills with a subtle zoom, produced with ffmpeg. There is no generated human motion or actual detection. The UI labels media and events as simulated. The ten-second analysis animation is independent of clip playback and does not measure a model's performance.
